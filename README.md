## Overview
The Heart Disease Prediction System is a Machine Learning-based project developed to predict the possibility of heart disease using patient medical information. The main goal of this project is to build a predictive model that can analyze health-related parameters and identify whether a person is at risk of developing heart disease.

This project uses **Logistic Regression**, a supervised machine learning algorithm used for binary classification problems. The model classifies patients into two categories: presence of heart disease or absence of heart disease based on input medical features.

## Project Workflow
The complete machine learning pipeline followed in this project includes:

- Data Collection
- Data Preprocessing
- Data Cleaning and Handling Missing Values
- Exploratory Data Analysis (EDA)
- Feature Selection
- Data Splitting into Training and Testing Sets
- Model Training using Logistic Regression
- Model Evaluation
- Heart Disease Risk Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Machine Learning Algorithm
**Logistic Regression**

Logistic Regression is used to build a classification model that predicts the probability of heart disease based on patient health parameters. It is efficient, simple, and suitable for binary classification tasks.

## Evaluation Metrics
The performance of the trained model is evaluated using:

- Accuracy Score
- Precision Score
- Recall Score
- F1-Score
- Confusion Matrix

## Objective
The objective of this project is to develop an intelligent prediction system that helps in early identification of heart disease risk. By analyzing important medical parameters, the model provides predictions that can support healthcare analysis and decision-making.

## Result
The trained Logistic Regression model successfully predicts heart disease risk based on user-provided medical information. The model performance is measured using various evaluation metrics to ensure reliable predictions.

This project demonstrates the application of Machine Learning in the healthcare domain and highlights how data-driven approaches can assist in early disease detection.
